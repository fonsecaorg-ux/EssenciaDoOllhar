# EssenciaDoOllhar
Aplicação web de agendamento e vitrine digital desenvolvida para o estúdio de design de sobrancelhas e estética Essência do Olhar (Kezia Fonseca). Construída com React, Tailwind CSS e Supabase (PostgreSQL).


# ✨ Essência do Olhar

Aplicação web desenvolvida para gerir o agendamento de horários e a vitrine de serviços do estúdio de estética **Essência do Olhar**, da profissional **Kezia Fonseca**.

## 🚀 Tecnologias Utilizadas
* **Frontend:** React, Tailwind CSS
* **Backend & Banco de Dados:** Supabase (PostgreSQL)

## 📱 Funcionalidades
* Vitrine de serviços com valores e durações (Design, Micropigmentação, Extensão de Cílios, etc.).
* Fluxo de agendamento interativo para clientes.
* Seção de perfil profissional e portfólio de trabalhos ("Antes e Depois").
* Painel integrado com banco de dados relacional seguro.
